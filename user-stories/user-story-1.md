# US-001: Simple Python To-Do App

**User Story**

As a user, I want a simple to-do application in Python so that I can manage my daily tasks.

**Acceptance Criteria**
1. Add a new task.
2. View all tasks.
3. Mark a task as completed.
4. Delete a task.
5. Handle invalid task IDs gracefully.
6. Include unit tests for all core operations.

**Constraints**
- Use Python.
- Use a command-line interface.
- Store tasks in memory; no database or external APIs.
- Keep the implementation simple and modular.
